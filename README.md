# NovaFlow — KAVIRO Studio Frontend Demo

A conceptual B2B SaaS landing page created by **KAVIRO Studio** as a public frontend demonstration.

**Live demo:** https://kaviro-novaflow-demo.vercel.app

> NovaFlow is a fictional product. This repository is presented as concept work, not as client work, and it contains no real customer data or fabricated client results.

## What this project demonstrates

- Conversion-focused landing page structure
- Responsive UI from desktop to mobile
- React / Next.js component thinking
- Custom CSS without a UI framework
- Product-dashboard composition using semantic HTML and CSS
- Clear hierarchy, spacing and CTA placement
- A structure that can be adapted for agency or client work

## Stack

- Next.js 15
- React 19
- Custom CSS
- Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## About KAVIRO Studio

KAVIRO Studio focuses on frontend delivery, responsive landing pages and conversion-oriented web experiences. This demo exists so potential collaborators can evaluate implementation quality and visual judgment without relying on unverified experience claims.
